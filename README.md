# Oakward Cursor Kit

1. Extract this ZIP and open the project folder in Cursor.
2. Paste the complete contents of CURSOR_PROMPT.md into Cursor Agent once.
3. Run the included website with `npm run dev`, or generate static hosting files with `npm run build`.

No package installation, API key or remote assets are needed. Node.js 18+ is required for the included server/build scripts.

Included: finished website, transparent owl logo, exact 1500×500 banner, two original square memes, one complete Cursor prompt, AGENTS.md, research/source links, bounded DEX snapshots, editable launch config and verified browser previews.

Oakward is an independent Ethereum meme concept. It is not Sherwood / WOOD and offers no guardian, vault or trading service. No real contract or social links have been supplied; the website works with honest pending states. Add only verified launch values to site-config.json when available. The kit neither deploys a token nor publishes a website.

QA_REPORT.md and previews/ record completed checks. PACKAGE_MANIFEST.json lists hashes. The generated dist/ copy is excluded from the ZIP because the supplied build script regenerates it immediately.
