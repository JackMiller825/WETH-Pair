# Spud Panic Cursor Kit

1. Extract this ZIP and open the project folder in Cursor.
2. Paste the entire CURSOR_PROMPT.md into Cursor Agent once.
3. The supplied site already runs with `npm run dev`. Create static hosting files with `npm run build`.

Node.js 18+ is required for the local server/build tools. No package installation, remote assets, API key or paid service is needed.

Included: complete site, transparent logo, exact 1500×500 banner, two original square memes, one complete Cursor prompt, AGENTS.md, detailed research/source links, classified current DEX sample, separate historical/indexed-record notes, pending launch config and browser preview images.

Spud Panic / SPUDP is an independent Ethereum meme concept. There is no endorsement or affiliation with Coplan, Polymarket or existing potato projects. Contract, tokenomics and social/trading links remain null until genuinely verified. The site works with pending controls; the kit does not deploy a token, perform a trade or publish a website.

QA_REPORT.md and previews/ record completed checks. PACKAGE_MANIFEST.json lists file hashes. dist/ is generated by the supplied build script and excluded from the ZIP to avoid duplicate assets.
